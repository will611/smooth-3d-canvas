# Mahaka Kreatif 3D Smooth Website

## Build
- Create a premium, mobile-first one-page commercial website using the supplied Mahaka Kreatif logo and real project photos.
- Use a restrained black, charcoal, white, cyan, and blue visual system with smooth depth, perspective, parallax, and scroll-reveal effects.
- Present services, ACP workflow, combined solutions, portfolio, production process, FAQ, and contact content from the supplied brief.
- Connect booking, service consultation, floating mobile action, and the quotation form directly to WhatsApp with contextual pre-filled messages.
- Add accessible navigation, image viewing, responsive layouts, reduced-motion support, and complete page metadata.

## Technical details
- Keep the experience lightweight with CSS 3D transforms and small React interactions rather than a heavy 3D engine.
- Store uploaded media through the project asset system and render responsive, lazy-loaded images.
- Keep quotation details in the browser only long enough to construct the WhatsApp message; no backend storage is implied.
- Verify the final page at mobile and desktop sizes, including motion, menu, gallery, FAQ, form, and external booking links.
